# Estructura del informe ejecutivo

> Este es el layout que genera automáticamente `report.generar_informe_markdown()`.
> Se documenta acá como referencia — no hace falta completarlo a mano, pero
> sirve para saber qué esperar y para revisiones manuales cuando el pipeline
> automático no pudo leer algún documento.

1. Título y metadatos (URL, fecha de generación)
2. Clasificación ★ con el desglose del puntaje
3. Resumen ejecutivo
4. Datos clave (organismo, número, fechas, garantías)
5. Criterios de evaluación detectados
6. Datos que faltan y dónde buscarlos
7. Productos Metropolitana identificados, por categoría, con evidencia
8. Riesgos detectados, por severidad, con evidencia
9. Checklist documental (exigido vs. estándar a verificar)
10. Cronograma de tareas
11. Documentos que no se pudieron leer (para revisión manual)
